Introducing

A web page is a page on the internet that you can open using a web browser. It can show words, pictures, videos, and links to help you learn, play, or find information.
A web page is a place where information can be presented and explored through a browser.

What is
WYSIWYG?

04 / 08
Understanding
“WYSIWYG”
WYSIWYG means “What You See Is What You Get.” It lets you create a web page and see how it looks while making it. It means what you see while editing is how it will look when finished.
Visual editing makes creating a web page easier because you can see the result while you work.
